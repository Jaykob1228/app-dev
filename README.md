# Fantastic Beasts and Where to Find Them

## Overview
A **magical** fantasy film series exploring the hidden wizarding world before the events of Harry Potter. It follows magizoologist *Newt Scamander* on his global adventures.

---

### Key Highlights
* **Author/Screenwriter:** J.K. Rowling
* **Genre:** Fantasy / Adventure
* **Theme:** Magical creatures, friendship, and the rise of dark wizardry.

### Main Characters
1. Newt Scamander (Magizoologist)
2. Tina Goldstein (Auror)
3. Jacob Kowalski (No-Maj / Baker)
